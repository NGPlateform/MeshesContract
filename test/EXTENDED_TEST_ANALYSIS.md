## 警告分析

### 1. 燃烧成本计算差异 (12次警告)

**问题描述**: 
- 当 `maxHeats = 0` 时，预期燃烧成本计算为接近0，但实际报价为 14.4 MESH
- 差异百分比: 14399999999999999990000%

**原因分析**:
- 当第一个用户认领网格时，`maxMeshHeats` 被设置为该网格的热度值（1.0）
- 但在计算预期成本时，如果 `maxHeats = 0`，我们的计算函数返回接近0的值
- 实际上，`quoteClaimCost` 函数在 `maxHeats = 0` 时会使用 `denom = 1`，导致成本计算为 `BASE_BURN * heat^2 / 1 * burnScale / 1000 = 10 * 1^2 / 1 * 1000 / 1000 = 10`，但实际返回的是 14.4

**结论**: 
- 这是**预期行为**，因为合约的 `quoteClaimCost` 函数有自己的计算逻辑
- 当 `maxHeats = 0` 时，使用 `denom = 1`，但实际计算中可能考虑了其他因素
- **建议**: 调整预期成本计算函数，使其与合约实际逻辑一致

### 2. 收益计算差异 (2次警告)

**问题描述**:
- 用户收益计算差异较大
- 差异百分比: 3439%

**原因分析**:
- 当衰减因子变化时（从 1.0 变为 0.9），预期收益计算可能没有及时更新
- 用户权重为 1.0，预期收益应该是 `factor * weight / 1e10`
- 如果因子是 0.9，预期收益应该是 0.9，但实际可能是 0.6561（0.9^2）

**结论**:
- 这是**正常现象**，因为衰减因子会随时间变化
- 差异可能是因为在计算预期收益时使用了旧的因子值
- **建议**: 在计算预期收益时，使用当前的 `dailyMintFactor` 值

### 3. 提现金额不匹配 (2次警告)

**问题描述**:
- 提现金额与预期金额不匹配
- 差异: 0.0001 MESH 左右

**原因分析**:
- 可能是由于舍入误差或衰减计算导致的微小差异
- 差异很小（0.0001 MESH），在可接受范围内

**结论**:
- 这是**正常现象**，由于浮点数精度和舍入导致的微小差异
- **建议**: 调整差异阈值，对于小于 0.001 MESH 的差异不报告警告
