# Meshes 合约详细测试说明

## 概述

本测试套件提供了对 Meshes 合约的全面数值分析和验证。每轮测试都会详细列出所有计算数值，并对数值的准确性和合理性进行分析。

## 测试文件

### 1. `Meshes.detailed-analysis.test.ts`
详细的数值分析测试，包含以下功能：

- **每轮测试详细输出**：包括所有状态变量、计算结果、事件数据
- **数值准确性验证**：对比预期值与实际值，检查差异
- **数值合理性分析**：验证数值之间的逻辑关系
- **多轮测试对比**：对比不同轮次之间的变化

## 测试场景

### Round 1: 初始状态分析
- 验证合约部署后的初始状态
- 检查所有初始值是否正确

### Round 2: 第一个用户认领网格
- 验证首次认领的免费机制
- 检查热度计算
- 验证状态变量更新

### Round 3: 第二个用户认领同一网格（需要燃烧）
- 验证燃烧机制
- 检查燃烧成本计算
- 验证燃烧金额准确性

### Round 4: 等待10分钟后首次提现
- 验证10分钟冷却时间（测试模式）
- 检查收益计算
- 验证供应量变化
- 检查 Treasury 分配

### Round 5: 等待10分钟（一个年周期）观察衰减
- 验证年衰减机制（测试模式：10分钟一个周期）
- 检查衰减因子变化
- 验证10%衰减率

### Round 6: 多个用户认领不同网格
- 验证多用户场景
- 检查各用户状态
- 验证网格热度计算

### Round 7: 综合场景
- 多轮操作组合测试
- 验证复杂场景下的数值准确性
- 检查权重增加对收益的影响

## 数值验证方法

### 1. 预期值计算
- **热度计算**：使用预计算表或公式 `1.2^n`
- **燃烧成本**：`BASE_BURN * (heat^2) / maxHeats * burnScale / 1000`
- **衰减因子**：每周期乘以 0.9（衰减10%）
- **收益计算**：`(dailyMintFactor * weight) / 1e10`

### 2. 差异检查
- 使用阈值判断（如 0.0001 MESH）来验证数值准确性
- 标记差异超出阈值的项目

### 3. 合理性验证
- 总供应量 >= 总燃烧量
- 活跃认领者数 <= 总认领次数
- 活跃网格数 <= 总认领次数
- 衰减因子在合理范围内 (0 < factor <= 1e10)
- 供应量变化合理
- 燃烧量不应减少

## 运行测试

```bash
cd MeshesContract
npx hardhat test test/Meshes.detailed-analysis.test.ts
```

## 测试模式时间调整

为了便于测试，合约中的时间限制已调整为：

1. **首次提现冷却时间**：从 24 小时改为 **10 分钟**
   - 常量：`TEST_FIRST_WITHDRAW_COOLDOWN = 600` 秒

2. **年衰减周期**：从 365 天改为 **10 分钟**
   - 常量：`TEST_YEAR_PERIOD_SECONDS = 600` 秒
   - 每 10 分钟相当于一个"年周期"，衰减 10%

这些调整仅用于测试环境，便于快速验证合约逻辑。
